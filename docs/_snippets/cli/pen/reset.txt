Discard a partial apply attempt: CAS-guarded local + remote branch cleanup

Usage: nave pen reset [OPTIONS] --request <REQUEST> <NAME> <BRANCH>

Arguments:
  <NAME>    Pen name
  <BRANCH>  Apply branch name (as provisioned by `pen branch`)

Options:
      --request <REQUEST>  Path to a JSON request file (`protocol_version`, per-repo `repo`/`expected_pushed_sha`)
      --json               Emit JSON instead of nothing
  -h, --help               Print help
