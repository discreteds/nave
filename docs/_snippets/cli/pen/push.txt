Push the apply branch's committed local tip, verifying evidence before reporting ok

Usage: nave pen push [OPTIONS] --request <REQUEST> <NAME> <BRANCH>

Arguments:
  <NAME>    Pen name
  <BRANCH>  Apply branch name (as provisioned by `pen branch`)

Options:
      --request <REQUEST>  Path to a JSON request file (`protocol_version`, per-repo `repo`)
      --json               Emit JSON instead of nothing
  -h, --help               Print help
